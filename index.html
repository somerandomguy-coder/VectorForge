VectorForge System Architecture

Zero-Cloud In-Browser Pipeline

  1. Web Worker AI Execution: The Web Worker checks for WebGPU support, compiles 16-bit float shaders, and executes distilled diffusion (SD-Turbo) via ONNX Runtime Web.
  2. OPFS Storage Streaming: Weights are streamed directly to the Origin Private File System using chunked ReadableStreams without crashing browser JS heap.
  3. Canvas Alpha Knockout: The raw bitmap is processed on an OffscreenCanvas with luminance thresholding to remove solid backgrounds client-side.
  4. Potrace Vector Tracing: The binarized mask is traced into high-precision SVG paths using the Potrace vector algorithm.
  5. Real-Time Recolor & Typography: Recolor SVG paths instantly with zero re-inference, format typography with clean vector text, and export to SVG, PNG, and multi-icon ICO.
